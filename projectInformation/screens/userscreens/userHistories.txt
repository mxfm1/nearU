# Casos de Uso del Sistema

## Módulo AUTH (Autenticación)

---

### AUTH-UH-001 — Registro de Usuario

**Actor:** Usuario

**Descripción**

El usuario requiere registrarse en la plataforma para acceder a las funcionalidades disponibles.

**Precondiciones**

* No poseer una cuenta registrada.

**Resultado esperado**

* Se crea una nueva cuenta de usuario.

---

### AUTH-UH-002 — Inicio de Sesión

**Actor:** Usuario

**Descripción**

El usuario requiere autenticarse utilizando sus credenciales para acceder a su perfil empresarial.

---

### AUTH-UH-003 — Recuperar Contraseña

**Actor:** Usuario

**Descripción**

El usuario solicita restablecer su contraseña mediante correo electrónico.

---

### AUTH-UH-004 — Cerrar Sesión

**Actor:** Usuario

**Descripción**

Permite finalizar la sesión activa del usuario.

---

### PROFILE-UH-001 — Crear Perfil Empresarial

**Actor:** Usuario

**Descripción**

El usuario crea el perfil de su empresa indicando información institucional y el propósito principal dentro de la plataforma.

---

### PROFILE-UH-002 — Editar Perfil Empresarial

**Actor:** Usuario

**Descripción**

Permite actualizar la información pública del perfil empresarial.

---

### PROFILE-UH-003 — Visualizar Perfil Empresarial

**Actor:** Usuario

**Descripción**

Permite consultar la información pública de un perfil empresarial.

---

### PROFILE-UH-004 — Administrar Multimedia del Perfil

**Actor:** Usuario

**Descripción**

Permite agregar, actualizar o eliminar el logotipo, imagen de portada y demás recursos institucionales del perfil.

---

### PROFILE-UH-005 — Configurar Tipo de Perfil

**Actor:** Usuario

**Descripción**

Permite indicar si la empresa ofrece servicios, organiza eventos o realiza ambas actividades.
